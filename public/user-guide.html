Time Assistant Guide

Plan calmly. Focus on one task. Move cleanly to the next one.

Time Assistant is a local-first desktop app for task transitions. It keeps your reminders, break flow, history, and settings on your machine without requiring an account or cloud sync.

Single active task Queue work, then start one task at a time.
Gentle reminders Choose more time, pause, complete, or dismiss for now.
Local history Review actions and export tasks or history as CSV.

Daily flow

1. Add a task

Enter a task name, pick the reminder time, and set how many reminder attempts should be allowed with what repeat interval.

  • name is required.
  • reminderCount must stay between 1 and 20.
  • reminderIntervalMinutes must stay between 1 and 240.

2. Start the current task

Starting a task makes it the active task. The timer and reminder scheduler track only that active item.

  • Pause if you need to stop temporarily.
  • Resume later without losing the task.
  • Complete when the session is done.

3. Respond to reminders

When a reminder appears, choose the next action instead of just closing a popup.

  • Add more minutes if you need extra focus time.
  • Pause the task if you are switching context.
  • Complete the task if it is finished.
  • Dismiss for now if you want to keep working.

4. Take a break

After completing a task, the app can prompt you to start a break. When the break ends, it can offer the next queued task.

  • The default break duration comes from Settings.
  • You can skip a break or stop it early.
  • Break actions are recorded in History.

Views and settings

Sticky note window

Turn on sticky mode to keep a compact companion window visible while you work in other apps.

  • Choose the sticky note color.
  • Control how many queued notes stay visible.
  • Keep the sticky note always on top if needed.

History and charts

The history panel logs important actions. Summary charts help you review completed tasks, focus minutes, category breakdown, and reminder behavior.

Notifications and sounds

Desktop reminders can play a sound and also show an in-app prompt when the app is open.

Theme and defaults

Settings let you choose light, dark, or system theme, plus default reminder and break values for new tasks.

CSV import and export

Time Assistant keeps data local, so CSV is the manual path for moving task data or reviewing history outside the app.

Task import

Import a CSV with at least name, reminderAt, reminderCount, and reminderIntervalMinutes.

Task export

Export includes task status, reminder state, timestamps, and pause totals.

History export

Export includes event type, timestamp, summary text, and metadata JSON.
